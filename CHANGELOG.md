# Changelog

Todas as mudanças relevantes deste projeto serão documentadas neste arquivo.

## [2.0.0] - 2026-01-17

### Added

- Implementação em **ECMAScript moderno**.
- Uso da **Fetch API nativa** do Node.js.

### Changed

- O projeto agora é **zero-dependency**.

### Removed

- Dependência do pacote `node-fetch`.
- Suporte a versões do Node.js anteriores à v20.0.0.
